# Project Summary – PS 32

## Introduction
The Online Food Ordering System is a Python console application developed to manage food orders and calculate the final bill.

## Working
The program displays a food menu and allows users to add or remove items from their cart. It also supports coupon discounts, GST calculation and delivery charges during checkout.

## Challenges Faced
- Managing food items and their quantities in the cart.
- Updating quantities when the same item is added again.
- Calculating discount and GST correctly.
- Applying delivery charges based on the subtotal.
- Handling invalid item names, quantities and coupon codes.

## What I Learned
- How to use lists and dictionaries together.
- How to create and use functions.
- How to manage cart items using list methods.
- How to perform billing calculations.
- How to handle invalid inputs using try-except.

## Conclusion
This project helped me understand how Python concepts can be used to build a simple real-world ordering system.
