# Online Food Ordering System (PS 32)

## About the Project
This is a Python-based console application that allows users to order food, manage their cart, apply coupons and generate a final bill.

## Features
- Displays available food items and prices.
- Add and remove items from the cart.
- Apply the SAVE10 coupon for a 10% discount.
- Calculates GST and delivery charges.
- Generates the final bill.

## Technologies Used
- Python 3
- Lists and Dictionaries
- Functions
- Loops and Conditional Statements

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Run the Python file using:

```bash
python Mainfile.py
```
